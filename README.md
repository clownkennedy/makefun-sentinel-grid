Sentinel Grid is an original 2D tower-defense game: build four kinds of sentinel towers along a winding road, upgrade and sell them, and hold the core through 20 escalating waves — including boss waves every five — with gold earned from every machine you destroy.

## Run it

```sh
node serve.ts
```
